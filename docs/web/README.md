# QuickNote Website

Source of [quicknote.srilakshmikanthanp.com](https://quicknote.srilakshmikanthanp.com/), built with React, Vite and Tailwind CSS.

> [!NOTE]
> This website was mostly generated with AI.

## Development

```sh
npm install
npm run dev      # start the dev server
npm run build    # build into dist/
npm run deploy   # build and publish to GitHub Pages
```

## Note editor

The demo note on the home page is `@quicknote/editor` (`packages/note-editor`), the same editor the desktop app uses. Edit it there, not here.
